# Website Sitemap Auditor

A lightweight web-based tool for auditing website sitemaps and URLs.

It helps developers and SEO teams identify common sitemap and URL-related issues quickly.

## Features

- Sitemap URL validation
- Sitemap XML analysis
- URL status checking
- HTTP status code detection
- Broken URL detection
- Redirect detection
- URL structure analysis
- Crawlability checks
- Basic technical SEO checks
- Easy-to-use interface
- No account required

## Use Cases

This tool can help you:

- Check whether a sitemap is accessible
- Find broken URLs
- Identify redirects
- Review sitemap URL structures
- Detect common sitemap configuration issues
- Perform quick technical SEO checks during development
